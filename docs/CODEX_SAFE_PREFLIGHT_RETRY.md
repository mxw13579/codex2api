# Codex HTTP 安全前置重试（实验性）

**默认关闭，尚未完成真实 Codex 客户端兼容性验收。** 本文描述代码行为，不代表已部署、已启用或建议直接在生产开启。

## 开关与覆盖范围

独立进程环境变量 `CODEX_SAFE_PREFLIGHT_RETRY=true`（或 `1`）启用候选功能；未设置、`false`、`0`、非法值均关闭。修改部署环境需要正常发布/重启流程。此开关不持久化到数据库、不增加管理员 UI 开关，也不会自动修改任何实际 `.env`。

此开关与已有 `codex_preflight_sse_passthrough_enabled` **相互独立**。只在满足以下条件时覆盖旧前置事件处理；其他请求保持原路径，原兼容开关仍按原语义生效：

- `/v1/responses` 的 SSE 流，Codex OAuth **HTTP 上游**；保持原有传输选择，不强制 WS 降级。
- 显式 HTTP/HTTPS 代理，以及受支持的标准 HTTP Transport。支持生产构造器配置的真实 HTTP/2，每个 attempt 建立独立发送池；不复用先前 HTTP/2 回调捕获的连接池，不关闭其他请求的连接。
- 简单文本输入；未声明工具；输出格式为普通文本或仅含 `type: json_object` 的格式声明。原转换器若自动添加 `image_generation`，该请求不进入新模式，不能将“开关打开”当作已经覆盖该请求。
- 普通及 429 重试预算均有限。连续重试、自动续想、自动压缩、Lite、流水线、输出扫描器、`previous_response_id`、turn-state/turn-metadata、工具结果、加密续链及未知控制输入均不进入本模式。

V1 **不覆盖** WS 上游/原生 WS 下游、relay、Agent Identity、直连/环境代理、SOCKS、Resin、uTLS、自定义协议发送器、任意 JSON Schema 输出。不会为适配此模式关闭过滤器、TLS 校验或改变出站路由。进入模式后遇到非法代理/发送器配置会在发送前失败，而不是回退直连。

## 可以先收到什么

只有通过严格 JSON schema 与完整 SSE envelope 检查的真实 `codex.rate_limits` 帧，才会以原始字节提前下发：

- 不伪造、不从本地配额合成、不重放旧帧。
- 不因下发该帧而冲刷尚未公开的 `response.created` / `response.in_progress`。
- JSON 最多 16 KiB、最多四层对象，无重复/未知字段；严格检查窗口、百分比、credits、有限的套餐/默认桶标识。它是保守子集，不是完整官方 schema。
- 可重放窗口的单帧 envelope 最多 1 MiB，待公开生命周期缓冲最多 64 KiB；越界终止，不把未知数据当作安全 metadata。协议提交后恢复原 SSE reader 的正常字段、EOF 尾事件与大帧兼容性。

配额帧表示**同一上游账户在本次逻辑请求中收到的配额观察**，可能来自稍后失败的 attempt。它不是 API Key 配额、最终剩余额度、请求准入凭证、最终账单或成功承诺；缺省窗口不是零，primary/secondary 不等于固定 5 小时/7 天。收到时间不证明上游数据生成时间，并发请求也可能改变配额。

## 重试与不可逆边界

- HTTP 200 已提交，不等于已公开模型响应。安全配额帧后，仍可按原错误分类和有限预算重试。
- 另有硬边界：**最多三次实际逻辑 attempt**，且只允许从原请求开始 **60 秒内开启新 attempt**；普通预算为 0 仍不重试。60 秒不是整段生成超时，已选定的正常长生成不被截断。
- 第一帧配额发布后，固定同一账户、credential generation、实际请求头/正文/URL/模型/会话和受支持的发送配置；在 quota 等待前后复核。正常账户、Key、scope、模型/代理与调度门禁仍生效；原身份不能重取就结束，不能换账户接着公开配额。
- 发送池独立不等于网络出口 IP 不变。配置/请求身份检查**不能证明代理服务的物理出口 IP、DNS 结果或外部代理内部路由恒定**。
- 观察到输出、reasoning、工具身份、未知语义/控制信息，或者发生协议提交、取消、局部/短写，就永久关闭透明重试资格。保留原有五秒有界 usage drain，不以“没文本”推断“未执行/未消耗”。
- 不承诺上游 exactly-once，也不承诺所有公开响应最终成功。只能丢弃尚未公开的失败 attempt；选定并公开响应后若再失败，该流直接失败。

## Header、终态与日志

失败 attempt 的 turn-state header 保持私有。若配额或心跳已经提交 HTTP headers，后续 attempt 的 turn-state 将省略，不虚构等价 SSE 字段，也不登记为已交付 provenance。

重试决定先于失败终态发布。不可重试的 standalone error 走原治理/状态/计费收尾；不允许先公开 error 再追加另一个 failed/completed。保留 cyber-policy、终态归一化、完成缓存及 quota 专用错误详情。

HTTP 已提交时仍可能最终失败：应区分 wire HTTP 200 与逻辑 400/429/499/502/503 等访问状态。发送前的本地拒绝不虚构上游 usage，也不处罚账户。

成功或失败终态完整本地写入、排空缓冲且 Flush 返回后，后到取消不会把已选定的语义结果改记为 499；内容后 EOF 的合成断流保留原逻辑 598。短写、带错误的写入、写前取消，以及只在 usage drain 中观察到终态，仍不能算作完整交付。这里的证据不是客户端 ACK 或解析确认，void Flush 也不能报告所有网络故障。暂为重试隐藏的失败，如果最终不能开启新 attempt，仍须发表唯一失败终态。

模型请求次数按同一逻辑请求记账，不等于上游执行次数或 token 账单。新模式对明确未发送的本地拒绝，只回收本次预留新增的额度记录；此前真实尝试、已进入可能发送阶段的失败和不确定传输仍保守计数。回收在本次 executor 返回前用短事务完成，不跨网络持有数据库事务，也不在后来关闭 body 时退款。存储或回收失败会停止后续发送、记录固定诊断并返回额度存储错误；下游已经取消时仍以 499 为优先。数据库故障时不承诺回收已经成功，不更换逻辑请求 ID 绕过额度。同步回收最多额外等待三秒，这是本地记账清理，并非延长上游五秒 usage drain。

## 验证与发布限制

本地验收包括真实 Handler、受信测试证书、真实 HTTP/1 与 HTTP/2、显式 loopback CONNECT 代理和下游读取屏障；另测三次上限、scope=1、SQLite quota 等待后的取消/身份变化、超过 1 MiB 的已提交事件和实际超过 60 秒的生成。

另有失败终态与合成断流的 immediate/coalesce 交付及晚取消矩阵、最终错误渲染短写、首次未发送额度回收、真实发送保守计数、receipt 幂等/并发/旧收据不删除后来计数和存储故障测试。重试窗口关闭的边界用例使用合成阶段时钟控制，不冒称实等 60 秒；已有超过 60 秒生成用例则实际等待生成完成。SQLite 故障注入不等于真实 PostgreSQL 故障验收。

这些合成测试不等于真实模型或客户端验收。实际客户端对提前配额、重复观察、生命周期顺序、缺省 turn-state、配额后直接失败的接受性，仍需单独授权验证。发布也须另行授权；不得据本文自动提交、部署、修改线上参数或启用开关。
